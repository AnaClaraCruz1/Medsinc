# Medsinc

## 📌 Descrição do Projeto

O Medsinc é um sistema desktop desenvolvido em Java com o objetivo de auxiliar no gerenciamento de informações médicas e administrativas de forma organizada, prática e eficiente.

O sistema foi desenvolvido como Projeto Integrador do curso Técnico em Desenvolvimento de Sistemas, aplicando conceitos de programação orientada a objetos, banco de dados e versionamento de código.

## 🎯 Objetivo do Software

O objetivo do Medsinc é facilitar o gerenciamento de registros médicos e administrativos, permitindo maior organização das informações cadastradas no sistema.

O software busca proporcionar praticidade no armazenamento, consulta, atualização e remoção de dados relacionados aos usuários e registros do sistema.

### 🔐 Login do Sistema
